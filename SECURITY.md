# Security Policy

## What this repo is

The Stop Authority Kit is a set of documents and templates: a checklist, a stop owner card, and a drill log. It contains no code, so there is nothing to install or patch.

## Reporting a problem

If you find something in the kit that could lead someone to a weaker stop than they think they have, or any other security concern, please report it privately:

- Email: myles@aihabits.ai
- Or use GitHub's "Report a vulnerability" button on this repo's Security tab.

Please don't open a public issue for a security concern.

## What to expect

I'll reply within 5 business days and let you know what I plan to change. Fixes go into the kit with a note in the commit history.

## Supported versions

Only the latest version on the `main` branch is supported.
